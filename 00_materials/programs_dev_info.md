# 程序开发委托任务

## 1. 委托原话

委托来自一位生物学教授，不太懂生信分析

```
现在很多公司推出了用纳米孔测序测 PCR 产物的服务 （https://www.tsingke.com.cn/products/sangerUltra）。理论上来说，这种测序结果是和常规的纳米孔测序结果一样，可以拿到每一条序列的准确信息的。但是公司没有这种对应分析软件。而每个小文库都让生信分析的同学去分析的话，数量又太多了。所以我想请你们帮忙写一个小程序。

输入是测序的 fastq 文件，以及目的序列，数量比例排名前 n （ n 是自定义变量）详细序列和数量占总数量的比例

（选择性功能）连接 gtf 那些信息，进一步注释它是有移码，提前终止，还是 missense 等等

总的来说，就是我想知道 PCR 产物里，有多少序列是我想要的序列是完全一样的，不一样的序列是什么样的，两者的占比如何
```

## 2. 我自认为程序最终需要达到的程度

- 程序最终有以下几个版本

    - .exe 的 windows GUI版本版本

    - R / python 脚本的终端版本

    - 将程序包装成 R 包 / python 模块，供其他同学使用，自由度更高

    - 在远程服务器完成部署，通过ip和端口在本地电脑浏览器即可使用程序
